# Changelog

## 2.0.0 - 2026-09-17

### Preserved

- Objective preservation, explicit governing constraints, one candidate editor, separate diagnosis, and unanimous approval across required review lenses on the same candidate.
- The original `THE-PERFECTION-SYSTEM.md` entry point, now a generated standalone edition.

### Changed

- Replaced mandatory agents with logical roles that work sequentially, in parallel where supported, or through human coordination.
- Replaced the absolute "Perfect" verdict with scoped, evidence-backed acceptance.
- Replaced an unlimited loop with a configurable finite budget, a three-cycle default, and explicit blocker, budget, stall, and cancellation outcomes.
- Replaced claims of no memory carryover and eliminated bias with versioned source grounding, an explicit finding ledger, and honest limits on review independence.
- Replaced indiscriminate full-context reloads with relevant authoritative context, exact checks of disputed constraints, and explicit context-limit handling.
- Made advisory improvements non-blocking and introduced conflict resolution without blindly applying every suggestion.

### Added

- A self-contained Agent Skills package with no vendor-specific tool permissions or configuration.
- Capability fallbacks, prompt-injection boundaries, authorization rules, immutable review snapshots, evidence requirements, regression checks, and cross-session handoffs.
- Optional templates, illustrative worked examples, behavioral evaluation cases, offline package validation, and automated tests of that validator.

### Limits

- Documentation and packaging checks do not establish live model behavior, security guarantees, or universal host compatibility.
- No runtime orchestrator, automatic deployment, new license grant, or vendor-specific integration is introduced.
